Citation
========

If you use Bioverse in your research, please cite:

.. code-block:: bibtex

   @software{bioverse2026,
     author = {Kucera, Tim and Bioverse Contributors},
     title = {Bioverse: A standardized framework for machine learning on biomolecules},
     year = {2026},
     url = {https://github.com/BorgwardtLab/bioverse},
     note = {Documentation: https://borgwardtlab.github.io/bioverse/}

A peer-reviewed paper is in preparation. Until publication, cite the software
entry above and link to the `GitHub repository
<https://github.com/BorgwardtLab/bioverse>`_.
